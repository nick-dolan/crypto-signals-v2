# Crypto Signals v2

Система раннего предупреждения о сильных движениях криптовалют в ближайшие 4–12 часов. На основе рыночных признаков агент оценивает вероятность движения и выделяет наиболее интересные монеты. Результаты, графики, новости и публикации Twitter сохраняются в Parquet, открываются в веб-интерфейсе и скачиваются автономным HTML.

## Архив и сервер отчётов

Запускать из корня проекта, в разных терминалах:

```sh
pnpm install
pnpm server
```

Список отчётов: **http://127.0.0.1:3000/**. Сервер работает независимо от пайплайна:

```sh
pnpm all
```

Авторизации нет: не публикуйте сервер в интернете без отдельной защиты доступа и HTTPS.

## Шаги

- **1. Список монет** — выбираем монеты с Binance USDT perpetual, исключаем стейблкоины и монеты с недоступными данными.
- **1.1. Описания монет** — добавляем описания новых монет со ссылками на проверенные источники.
- **2. История данных** — загружаем почасовые данные; монеты с неполной историей временно пропускаем.
- **3. Общий рынок** — загружаем капитализацию рынка и его основных сегментов.
- **3.1. Тренды CoinGecko** — получаем популярные монеты и категории, находим совпадения с нашим списком.
- **4. Признаки** — рассчитываем признаки раннего движения, устойчивую силу и рыночный фон.
- **5. Предварительный отбор** — оставляем кандидатов с ранними сигналами, исключаем уже зрелые движения.
- **6. Данные для агента** — собираем компактные профили отобранных монет.
- **7. Основной анализ** — GPT-6-Astra оценивает вероятность сильного движения без прогноза направления и выбирает до пяти монет.
- **8. Новости** — собираем свежие новости для топа агента и трендовых монет из основного отчёта.
- **9. Twitter** — собираем публикации за последние сутки для тех же монет.
- **10. Информационный фон** — Gemini 3.7 Flash дополняет объяснения новостями и обсуждениями, выделяет значимые инфоповоды.
- **11. Радар соседей** — независимо от основного отбора ищем монеты, отстающие от свежего роста прямых соседей.
- **12. Анализ радара** — Claude Opus 5.5 объясняет расхождения и выделяет наблюдения, заслуживающие внимания.
- **13. Отчёт** — сохраняем основной анализ и радар соседей в архив для просмотра на сайте и скачивания одним HTML-файлом.

## Исследование характера цены PROVE · 15m

Отдельный эксперимент, не меняющий основной пайплайн:

```sh
pnpm research:prove
pnpm research:prove --cached
```

Первый запуск запрашивает через TradingView до 90 дней закрытых свечей `BINANCE:PROVEUSDT.P` на 15m и сутки для фона. Использует существующие `TV_SESSIONID` и `TV_SESSIONID_SIGN`. Если доступна более короткая история, анализирует полные дни (не меньше 30) с явным предупреждением; пропуски и повреждённые свечи не заполняет. Второй запуск пересчитывает сохранённую выборку без сети и без обновления её даты.

Результаты в `reports/prove-15m/`:
- `candles.json` — использованные свечи, включая прогрев;
- `report.json` и `report.md` — показатели за 7/30 дней и всю доступную историю, недели и крупнейшие вспышки;
- `report.html` — автономный график и таблицы, открывается без сервера и сети.

Измеряем равномерность диапазона свечей, вспышки относительно предыдущих суток, длинные тени, направленность движения и его концентрацию в отдельных свечах. Амплитуда и приблизительный оборот учитываются отдельно. Это исследовательские признаки, не рейтинг, прогноз или готовый отбор похожих монет. При новом запуске без `--cached` предыдущая выборка этого эксперимента заменяется.

Проверки: `pnpm test`.

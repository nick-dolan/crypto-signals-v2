# Crypto Signals v2

## HTML-отчёт — шаг 7.1

После анализа агента автоматически создаётся `tmp/step7.1-report.html`. Откройте его обычным браузером: файл содержит данные, стили и Lightweight Charts и работает без сервера, сборки и интернета.

Чтобы пересоздать только отчёт из сохранённых результатов:

```sh
pnpm exec node src/step7.1-report.js
```

Нужны результаты шагов 5, 6, 7 и часовая история из `tmp/step2-data-bootstrap`. Повторных запросов к агенту или источникам данных нет.

- Сводка рынка, топ агента, поиск и сортировка всех кандидатов.
- Часовые свечи за неделю, объём и Open Interest на общей временной шкале; по умолчанию видны 3 дня, доступны 1 / 3 / 7 дней.
- Объяснения, аргументы за и против, признаки с описаниями, ссылки на TradingView.
- Пропуски истории явно отмечаются; отсутствующие значения не заменяются нулями.

Это снимок шага 7, без новостей и публикаций последующих шагов. Время свечей — UTC, по открытию последней закрытой свечи (`asOf`). Вероятности остаются оценкой агента, не статистически откалиброванным прогнозом.

`pnpm all` запускает отчёт между шагами 7 и 8. Следующий полный запуск очищает `tmp`, поэтому нужные отчёты стоит сохранять отдельно.

# Crypto Signals v2

Система раннего предупреждения о сильных движениях криптовалют в ближайшие 4–12 часов. На основе рыночных признаков агент оценивает вероятность движения и выделяет наиболее интересные монеты. Результаты, графики, новости и публикации Twitter сохраняются в Parquet, открываются в веб-интерфейсе и скачиваются автономным HTML.

## Архив и сервер отчётов

Запускать из корня проекта, в разных терминалах:

```sh
pnpm install
pnpm server
```

Список отчётов: **http://127.0.0.1:3000/**. Сервер работает независимо от пайплайна:

```sh
pnpm all
```

Авторизации нет: не публикуйте сервер в интернете без отдельной защиты доступа и HTTPS.

## Локальное превью карточки монеты

Статичная инфографика на D3 + resvg: цена, объём и Open Interest за 72 закрытых часа, изменения цены за 4/24 часа, оценка агента. Браузер и сеть не нужны; шрифт с кириллицей включён в проект.

```sh
pnpm report:card
pnpm report:card --symbol SNX
```

По умолчанию берётся первый топ-кандидат из последнего сохранённого отчёта. `--symbol` выбирает конкретную монету; `--report` позволяет указать ID другого отчёта из архива. Если топ пуст, монету нужно выбрать явно. SVG и PNG сохраняются в `output/coin-card/` под именем монеты; повторное превью той же монеты заменяет эти файлы, не меняя архив.

Пустой архив не подменяется демо-данными. Для проверки оформления без готового отчёта:

```sh
pnpm report:card --demo
```

Получатся `output/coin-card/DEMO.svg` и `output/coin-card/DEMO.png` с заметной пометкой о синтетических данных. Это не рыночный сигнал. Превью не подключено к пайплайну и ничего не отправляет в Telegram.

Время на карточке — закрытие последней свечи (`asOf + 1ч`), в МСК. Пропуски остаются пропусками; при отсутствии последней свечи старая цена не показывается как актуальная. Изменения цены и OI вычисляются по точным концам соответствующих окон, а относительный объём берётся из готовых признаков отчёта. Объём и OI на графиках — в базовом активе, не в долларах.

## Шаги

- **1. Список монет** — выбираем монеты с Binance USDT perpetual, исключаем стейблкоины и монеты с недоступными данными.
- **1.1. Описания монет** — добавляем описания новых монет со ссылками на проверенные источники.
- **2. История данных** — загружаем почасовые данные; монеты с неполной историей временно пропускаем.
- **3. Общий рынок** — загружаем капитализацию рынка и его основных сегментов.
- **3.1. Тренды CoinGecko** — получаем популярные монеты и категории, находим совпадения с нашим списком.
- **4. Признаки** — рассчитываем признаки раннего движения, устойчивую силу и рыночный фон.
- **5. Предварительный отбор** — оставляем кандидатов с ранними сигналами, исключаем уже зрелые движения.
- **6. Данные для агента** — собираем компактные профили отобранных монет.
- **7. Основной анализ** — GPT-6.1 Sol оценивает вероятность сильного движения без прогноза направления и выбирает до пяти монет.
- **8. Новости** — собираем свежие новости для топа агента и трендовых монет из основного отчёта.
- **9. Twitter** — собираем публикации за последние сутки для тех же монет.
- **10. Информационный фон** — Gemini 3.7 Flash дополняет объяснения новостями и обсуждениями, выделяет значимые инфоповоды.
- **11. Радар соседей** — независимо от основного отбора ищем монеты, отстающие от свежего роста прямых соседей.
- **12. Анализ радара** — GPT-6.1 Sol объясняет расхождения и выделяет наблюдения, заслуживающие внимания.
- **12.1. Короткая сводка рынка** — собираем общую криптоленту TradingView и поиск Twitter за последние 6 часов; Gemini 3.7 Flash пишет один-два абзаца, суммарно до 800 символов.
- **13. Отчёт** — сохраняем основной анализ, сводку событий и радар соседей в архив для просмотра на сайте и скачивания одним HTML-файлом.

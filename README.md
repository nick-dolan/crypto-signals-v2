# Crypto Signals v2

## HTML-отчёт — шаг 11

После обогащения контекстом на шаге 10 автоматически создаётся `tmp/step11-report.html`. Откройте его обычным браузером: файл содержит данные, стили и Lightweight Charts и работает без сервера, сборки и интернета.

Чтобы пересоздать только отчёт из сохранённых результатов:

```sh
pnpm exec node src/step11-report.js
```

Нужны результаты шагов 5, 6, 7, 9, 10 и часовая история из `tmp/step2-data-bootstrap`. Шаг 9 уже содержит новости шага 8. Повторных запросов к агенту или источникам данных нет.

- Сводка рынка, топ агента, поиск и сортировка всех кандидатов.
- Часовые свечи за неделю, объём и Open Interest на общей временной шкале; по умолчанию видны 3 дня, доступны 1 / 3 / 7 дней.
- Объяснения, аргументы за и против, признаки с описаниями, ссылки на TradingView.
- Для топ-5 — дополненное объяснение шага 10 и раскрываемые новости/Twitter: тексты, источники, даты, ссылки и показатели активности.
- «Ничего не найдено» и «Ошибка загрузки» показаны отдельно. Пропуски истории не заменяются нулями.

Рыночные оценки и графики остаются снимком шага 7; вероятности и аргументы не пересчитываются после добавления информационного фона. Время свечей — UTC, по открытию последней закрытой свечи (`asOf`). Окна сбора новостей и Twitter указаны отдельно: они могут заканчиваться позже рыночного среза. Результаты с разными снимками или составами топа не объединяются. Вероятности остаются оценкой агента, не статистически откалиброванным прогнозом.

`pnpm all` запускает отчёт последним, после шага 10. Следующий полный запуск очищает `tmp`, поэтому нужные отчёты стоит сохранять отдельно.

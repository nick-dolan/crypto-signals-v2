# Crypto Signals v2

Система раннего предупреждения о сильном росте криптовалют в ближайшие 4–12 часов. Агент оценивает вероятность роста по рыночным признакам, новостям и Twitter. Результаты, графики и публикации сохраняются в Parquet, открываются в веб-интерфейсе и скачиваются автономным HTML.

## Установка Copilot на Ubuntu

Установите CLI без `sudo`:

```sh
curl -fsSL https://gh.io/copilot-install | bash
~/.local/bin/copilot
```

В Copilot выполните `/login`. После выхода определите путь:

```sh
export PATH="$HOME/.local/bin:$PATH"
which copilot
```

Чтобы SDK использовал установленный CLI, укажите полученный абсолютный путь в `.env`, например:

```dotenv
COPILOT_CLI_PATH=/home/nick/.local/bin/copilot
```

**OpenAI:** для `openai-unofficial` нужен отдельный вход в ChatGPT. После `pnpm install` выполните из корня проекта под пользователем сервиса, без `sudo`:

```sh
pnpm exec node --input-type=module -e 'import { getUnofficialOpenAISession } from "./src/api/openai-unofficial/auth.js"; await getUnofficialOpenAISession({ login: true })'
```

Подтвердите код по ссылке из терминала в браузере своего компьютера в течение **15 минут**. Сессия сохраняется в `.openai-token.json`; не добавляйте его в Git.

## Архив и сервер отчётов

Запускать из корня проекта, в разных терминалах:

```sh
pnpm install
pnpm server
```

Список отчётов: **http://127.0.0.1:3000/**. Сервер работает независимо от пайплайна:

```sh
pnpm all
```

Авторизации нет: не публикуйте сервер в интернете без отдельной защиты доступа и HTTPS.

## Шаги

- **1. Список монет** — выбираем монеты с Binance USDT perpetual, исключаем стейблкоины и монеты с недоступными данными.
- **1.1. Описания монет** — добавляем описания новых монет со ссылками на проверенные источники.
- **2. История данных** — загружаем почасовые данные; монеты с неполной историей временно пропускаем.
- **3. Общий рынок** — загружаем капитализацию рынка и его основных сегментов.
- **3.1. Тренды CoinGecko** — получаем популярные монеты и категории, находим совпадения с нашим списком.
- **4. Признаки** — рассчитываем признаки раннего движения, устойчивую силу и рыночный фон.
- **5. Предварительный отбор** — оставляем кандидатов с ранними сигналами, исключаем уже зрелые движения.
- **6. Новости** — собираем свежие новости для всех предварительно отобранных монет.
- **7. Twitter** — собираем публикации для тех же монет.
- **8. Информационный фон** — готовим краткие сводки новостей и Twitter с оценкой тональности.
- **8.1. Паттерны графика** — мини-агенты описывают актуальную структуру цены и объёма кандидатов.
- **9. Данные для агента** — объединяем рыночные признаки, паттерны и информационный фон кандидатов.
- **10. Основной анализ** — оцениваем вероятность сильного роста и выбираем наиболее интересные монеты.
- **11. Радар соседей** — независимо от основного отбора ищем монеты, отстающие от свежего роста прямых соседей.
- **12. Анализ радара** — GPT-6.1 Sol объясняет расхождения и выделяет наблюдения, заслуживающие внимания.
- **12.1. Короткая сводка рынка** — выделяем главные события рынка из новостей и Twitter.
- **13. Отчёт** — сохраняем результаты в архив для просмотра на сайте и скачивания.
- **14. Telegram-выпуск** — публикуем сводку и карточки кандидатов в Telegram.

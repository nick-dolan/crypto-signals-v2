# Выработанные правила

- При проверке и сохранении берём только завершённые часы; текущий незакрытый час отбрасываем.
- Принимаем только монеты с полной непрерывной историей строгого ядра; более короткое окно оставили только для Volume Delta.
- Social всегда запрашиваем всеми четырьмя рядами и используем только целиком при полных 2 400 завершённых часах и полном наборе рассчитанных признаков.
- Если Social недоступен, монету с полным ядром сохраняем, помечаем Social как `unavailable`, а его признаки и зависимые флаги оставляем `null`.
- Сбои только Social не создают coverage-исключений и не блокируют повторную проверку монеты.
- Монеты, у которых строго обязательного показателя нет вообще, запоминаем и временно не берём в следующие запуски.
- Пустая категория разрешена.
- Рынки связываем с монетами по уникальному идентификатору; контракты вроде `1000PEPE` не берём.
